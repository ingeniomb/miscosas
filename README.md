# Proyectos de electrónica, IoT y redes

Repositorio de trabajo para organizar proyectos desarrollados y probados en Arduino, ESP32 y Raspberry Pi.

## Proyectos incluidos

### `esp32-s3-lm35-dashboard/`
Sistema IoT con ESP32-S3, sensor LM35, pantalla OLED SH1106, Wi-Fi, servidor HTTP y dashboard web en tiempo real.

### `raspberry-pi-redes-iot/`
Prácticas para Raspberry Pi 2 B+ / 3: diagnóstico, Kea DHCP, Apache, Python CGI, dashboard web, DHT11 y control de LED.

### `esp32-s3-cam/`
Proyecto de cámara web con ESP32-S3-CAM y OV2640. Se conserva como versión reconstruida a partir de la versión probada en hardware.

## Seguridad

No se deben guardar aquí contraseñas Wi-Fi, tokens de Telegram, claves API ni otros secretos. Los ejemplos usan marcadores de posición.

## Cómo trabajar con este repositorio

1. Cada proyecto vive en su propia carpeta.
2. El código fuente se guarda junto a un `README.md` con conexiones, requisitos y forma de uso.
3. Los cambios se registran mediante commits, creando un historial recuperable.
4. Desde ChatGPT se puede pedir revisar, explicar, comparar o modificar el código conectado a GitHub.
